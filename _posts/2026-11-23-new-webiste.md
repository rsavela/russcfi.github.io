This is my new website!


## Why al-folio

I wanted a static site generator, and Jekyll seemed like a good choice, as I already use it for other sites.  `al-foloio` provides a bunch of Github Actions tooling that I didn't want to re-invent myself.  And it runs on Github Pages hosting, which is one less thing for me to pay for and maintain.  

Other than a bit of a learning curve with the workflow, and needing to go from `ubuntu-latest` to `ubuntu-20.24` to eliminate some rendering errors, it was easy to set up.

## What's next?

There are a ton of sample posts, and I like the batteries included approach.  Now, it is time to get to work replacing all of them with my own content. Stay tuned!
